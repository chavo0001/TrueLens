# TrueLens

TrueLens is a photography-focused social web app where users can create a profile, upload their photos, explore other users' content, like images, follow creators, and view EXIF details of each shot.

## Technologies
- JavaScript
- React
- Node.js
- Express
- PostgreSQL
- OOP
- SQL

## Features
- User registration with email confirmation
- Login and logout with session authentication
- Personal and public profile pages
- Photo upload with local storage
- EXIF data viewer for uploaded photos
- Like system for photos
- Follow and unfollow system
- Explore page to discover photos from other users
- Profile editing with avatar, bio, and password update

## Goal

I created this project to build a complete full-stack web app centered around photography, combining social features with photo metadata and user interaction.
